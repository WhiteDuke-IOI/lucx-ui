# lucx-ui
This repo is a simply wrapper over the [AlexeyLCP/lucx-ui](https://github.com/AlexeyLCP/lucx-ui/) repository for building a publicly avalible Docker image with built-in awg-tools+amneziawg-go and wg-tools
Also support [AmneziaWG DKMS](https://github.com/amnezia-vpn/amneziawg-linux-kernel-module) on host machine.
